# 更新类型 packages/types

根据以下参考信息，检查 packages/types 是否需要更新，包括但不限于代码本身和代码注释。若需要，则更新。

1. https://uniapp.dcloud.net.cn/collocation/pages.html
2. https://doc.dcloud.net.cn/uni-app-x/collocation/pagesjson.html
3. 两个页面上的外链
4. 代码注释内的链接

要求：

1. 统一的注释格式，使用 JSDoc
2. 统一的命名方式，参考现有代码
3. 规范的表达，遵循 https://github.com/ruanyf/document-style-guide
4. 链接页面的内容可能表达不规范、不通顺、不连贯，具体信息可能分散在页面各处，不要照抄，需要整合优化
5. 检查并处理其它不利于阅读和理解的因素
